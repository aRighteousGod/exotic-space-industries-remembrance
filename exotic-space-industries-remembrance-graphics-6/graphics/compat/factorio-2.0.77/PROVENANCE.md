# Retained Factorio 2.0.77 graphics

These original Wube Software Factorio graphics support ESIR's authored Metalworks
and Neo assembler compositions and the steam oil pumpjack shadow. Factorio 2.1
replaced their native sheets and frame geometry; these retained copies preserve
the existing ESIR masks, frame synchronization, scales and offsets.

Sources: the installed Factorio 2.0.77 `data/base/graphics/entity/` tree,
`assembling-machine-{1,2,3}/assembling-machine-{1,2,3}{,-shadow}.png` and
`pumpjack/pumpjack-horsehead-shadow.png`. Copyright Wube Software; these game
assets retain Factorio's applicable terms and are not relicensed as ESIR code.

The upgrade's protected `source-port/retained-art.json` records SHA-256 hashes.
