# Minigun turret delivery

The standard-resolution replacement is complete in Graphics 6 and main ESIR
1.3.42. It retains the 3×3 footprint and existing combat stats, with a fixed
foundation, 256-direction upper assembly, independently spinning five-barrel
rotor, 28 stored poses, 12-frame preparation, 18-frame folding and running blur.
Item/entity and research icons use the enlarged front three-quarter view.

The optional external companion is `minigun-turret-HD` major version 1. Its
source and HD artwork are maintained separately and are excluded from this
repository delivery. Main's complete SD profile works without it. The companion
adds standalone gameplay only when main is absent; that code is not loaded here.

Original native acceptance covers SD/HD color and combined-shadow reconstruction
and all four SD/HD × Ballistic Divergence firing configurations. The retained
matrix covers all 256 static directions, native flash animation and first tracer
evidence. Maximum measured flash attachment error was 1.582 native pixels.
The integrated profiles retain the exact calibrated 256 launch tuples and native
launch-field presence. Legacy Graphics 3 assets remain available to older users.

The final item-icon revision and all SD atlas PNGs are unchanged from the approved
shipping source. Complete SD archives fit the project limit of 256,000,000 bytes.
Raw captures, batch journals and scenes remain in local evidence staging rather
than shipping archives. The source GLB and prepared Blender scene are already
archived in `models/minigun-turret.glb` and `models/minigun-turret.blend` using LFS.

Read `HANDOFF-SEPARATED.md` for the mechanical/render contract and generator
commands. Earlier pilot, attack-clock and lifecycle notes retain their original
historical status; they are not a current work queue. The shared housekeeping
helper is included because the render and native-check launchers import it.
