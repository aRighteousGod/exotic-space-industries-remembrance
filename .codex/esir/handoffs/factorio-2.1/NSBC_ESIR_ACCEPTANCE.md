# NSBC consumer acceptance for ESIR 1.4.0

This supplements the standalone continuation's 2026-10-24 validation record.
It does not rewrite that historical record or claim physical keyboard/mouse
testing, a complete blueprint-library UI route, or native-language certification.
Publication remains gated on the final rebuilt packages and the ESIR synopsis.

Exact engine: Factorio 2.1.23, build 87750. Consumer: ESIR 1.4.0 development
source. Library: Nonstandard Beacons Continued 1.0.0, with published PEREL 1.2.2.
All runs use isolated profiles; the preserved 2.0 installation remains intact.

The complete ESIR consumer now uses `disabled_by_script` for overload control.
Full-core checks cover both declared replacement families, eight tier/quality
handoffs, exact fuel/fluid and orientation custody, module-overflow refunds and
the weighted overload transition 4 -> 5 -> 4. The connected native client checks
128 blueprint transforms, guarded normal/remote/editor rotation and source
information panels. Actual robot and platform replacements and six ruined-beacon
repairs pass. The populated legacy-library donor migrates and reloads successfully.

An independent whole-world ownership audit checks 131 beacon bodies and 262
helpers across all surfaces: zero orphan helpers, zero unregistered bodies and
zero multiply owned helpers. Source, manager, monitor and mimic roles are checked
where applicable. This is separate from the standalone protected-recovery tests.

Full-core multiplayer uses a private dedicated server and one real graphical
peer, followed by disconnect and rejoin. Both rare beacon bodies, modules,
orientation and owned helpers persist, with matching server/client reports and
no reported desync. It supplements the standalone two-client test; it is not a
long-running production-server soak.
